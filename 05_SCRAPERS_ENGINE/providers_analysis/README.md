## ⚡ معمارية الدمج والتبديل التلقائي الذكي (Failover Pipeline)

```
        [المستخدم يبحث عن فيلم أو مسلسل]
                      │
        ┌─────────────┴─────────────┐
        ▼                           ▼
[البحث المتوازي في 24 منصة]   [استبعاد المواقع غير المتاحة]
        │
        ▼
[تجميع كل السيرفرات في قائمة موحدة مرتبة بالسرعة والجودة]
        │
        ├─► 1. السيرفر المباشر الأول (Uqload / Vidmoly / Akwam Direct)
        │       │
        │       ├─► نجح التشغيل: ExoPlayer بأعلى جودة (1080p / 720p)
        │       └─► فشل / 404 خلال 1.2 ثانية: انتقال فوري للسيرفر التالي
        │
        ├─► 2. السيرفر البديل الثاني (FaselHD AJAX / CimaNow Resolve)
        │       │
        │       └─► استخراج رابط HLS متعدد الجودات
        │
        └─► 3. الدرع الأخير: مشغل WebView المصفى ضد الإعلانات والنوافذ المنبثقة
```

### القواعد الهندسية الصارمة:
1. **لا تجميد للشاشة (Zero Freeze):** الكشف الفوري عن صفحات 404 أو السيرفرات المحذوفة يتم خلال 1.2 ثانية بدلاً من الانتظار لـ 40 ثانية.
2. **التحكم في الجودات (Multi-Quality HLS):** يتم استخراج جودات (1080p, 720p, 480p, 360p) من تدفقات `master.m3u8` وربطها بقائمة اختيار الجودة في المشغل.
3. **تخطي الحمايات والإعلانات:** تجاوز جدران الحماية بالرؤوس القياسية (`User-Agent`, `Referer`, `CSRF Tokens`) وتصفية كل أكواد الإعلانات والنوافذ المنبثقة.
