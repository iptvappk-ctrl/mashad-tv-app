# منصة مَشْهَدْ TV — النسخة الويب (Mashhad Web)

أقوى وأسرع نظام ويب لمشاهدة السينما (أفلام ومسلسلات عرب سيد) وبثوث مباريات كرة القدم والقنوات التلفزيونية (سيرفرات ياسين تيفي) مع مشغل مخصص فائق الأداء وخالي من الثغرات، وجزء لا يتجزأ من منظومة [مشهد TV الشاملة](../README_AR.md).

---

## 🌟 الميزات والمواصفات الأساسية

### 1. 🎬 سينما مشهد (Arabseed Engine)
- **جلب مباشر وتحديث لحظي:** أحدث الأفلام والمسلسلات العربية والأجنبية والتركية والأنمي.
- **مفكك شفرات Mohix & Govid:** يفك تشفير سيرفرات المشاهدة الداخلية لـ Arabseed ويستخرج رابط الـ `.m3u8` أو الـ `.mp4` الأصلي عالي الجودة مباشرة.
- **تفاصيل العمل والمواسم والحلقات:** عرض بوستر بجودة عالية، قصة العمل، تقييمات، قائمة السيرفرات المتعددة، وتصفح سلس لجميع الحلقات والمواسم.

### 2. ⚽ بثات الكورة والقنوات (Yacine Engine + ESPN Live Score)
- **فك تشفير استجابات Yacine API:** محرك تشفير وفك تشفير ديناميكي (XOR + tHeader) لجلب باقات القنوات (beIN Sports, SSC, Abu Dhabi Sports, Netflix, OSN وغيرها).
- **جدول ونتائج مباريات اليوم لايف:** تكامل حي مع ESPN Soccer Scoreboard لعرض مواعيد المباريات، نتائج حية، الدقيقة الحالية، وحالة المباراة (مباشر 🔴، قريباً، انتهت).
- **بثوث المباريات المباشرة:** استخراج الروابط المباشرة للقنوات والأحداث الرياضية فور بدئها.

### 3. 🛡️ الـ Stream Proxy وسد الثغرات (Zero Vulnerabilities)
- **حل قيود CORS في المتصفحات:** سيرفر وسيط ذكي يعيد كتابة ملفات الـ `.m3u8` ويوجّه كل الـ Segments عبر الـ Proxy مع ترويسات `Access-Control-Allow-Origin: *`.
- **حماية كاملة من ثغرات SSRF:** فحص صارم للنطاقات وعناوين الـ IP؛ يمنع أي محاولة للوصول إلى العناوين المحلية (localhost, 127.0.0.1, 10.x, 192.168.x, 172.16-31.x) أو بيانات السحاب (169.254.169.254).
- **معدل الطلبات (Rate Limiting):** نظام حماية مدمج يعتمد على نافذة زمنية لمنع هجمات الـ DDoS والإغراق.
- **صفر ثغرات (0 Vulnerabilities):** فحص أمني دقيق بـ `npm audit` خالٍ بنسبة 100% من أي ثغرات برمجية.

### 4. 🎨 مشغل سينمائي متكامل (PlayerModal)
- مشغل فيديو مخصص بالكامل بثيم **الذهب والأسود الفخم (Dark & Gold)**.
- دعم كامل لتقنية **Hls.js** مع التعافي التلقائي من أخطاء الشبكة والوسائط.
- إمكانية التبديل بين السيرفرات وجودات الفيديو (1080p, 720p, 480p, Auto).
- دعم كامل لاختصارات لوحة المفاتيح:
  - `Space` أو `K`: تشغيل / إيقاف مؤقت.
  - `F`: شاشة كاملة (Fullscreen).
  - `M`: كتم الصوت.
  - `الأزرار يمين/يسار`: تقديم وتأخير 10 ثوانٍ.
  - `Esc`: إغلاق المشغل.
- دعم وضع صورة داخل صورة (Picture-in-Picture).
- جاهز كـ **PWA** للتثبيت الفوري كبرنامج على الكمبيوتر أو الموبايل.

## 🚀 طريقة التشغيل

### تشغيل خادم التطوير (Development):
```bash
npm run dev
```
ثم افتح المتصفح على: `http://localhost:3000`

### بناء النسخة الإنتاجية (Production):
```bash
npm run build
npm start
```
