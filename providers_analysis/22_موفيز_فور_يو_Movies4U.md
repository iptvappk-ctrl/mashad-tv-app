# توثيق وتحليل منصة موفيز فور يو (Movies4U) الشامل

---

## 1. بطاقة تعريف المنصة (Overview)

| البند | التفاصيل |
| :--- | :--- |
| **اسم المنصة** | موفيز فور يو — Movies4U |
| **الدومين الشغال حالياً** | `https://movies4u.icu` |
| **دومينات بديلة وشبكة التحميل** | `https://m4udl.store` \| `https://movies4u.tv` \| `https://movies4u.co` |
| **نوع المحتوى** | أفلام هوليوود، بوليوود مدبلجة، سينما أجنبية بدقة 4K و 1080p |
| **محرك الموقع (CMS)** | تطبيق ويب حديث مبني على Next.js 14/15 مع React App Router |
| **طبيعة الحماية** | شبكة توزيع سحابية CDN مع بوابة تحويل وتحميل منفصلة (`m4udl.store`) |

---

## 2. بنية الروابط ومحرك البحث (Search & URL Routing)

### أ. نقطة البحث المباشر (Search Endpoint)
* **الرابط:** `https://movies4u.icu/?s={query}`
* **طريقة الإرسال:** `GET`
* **معامل البحث:** `s` (مثال: `https://movies4u.icu/?s=batman`)

### ب. هيكل روابط المواد والتحميل/البث:
* **صفحة الفيلم الرئيسية:** `https://movies4u.icu/movie/{slug}`
  (مثال: `https://movies4u.icu/movie/ant-man-and-the-wasp-quantumania-2023-hindi-dubbed-web-dl-hd-download`)
* **بوابة روابط البث والتحميل المباشرة:**
  `https://m4udl.store/download/{slug}`

---

## 3. محددات الاستخراج (DOM & React Selectors)

### أ. بطاقات الأفلام في نتائج البحث:
* **حاوية الشبكة:** `div.grid` أو `div.movies-list`
* **عنصر البطاقة:** `div.movie-card` أو `a[href*="/movie/"]`
* **رابط الفيلم:** `a[href*="/movie/"]`
* **عنوان الفيلم:** `h2` أو `span.movie-title`
* **البوستر:** `img[src*="/img/t/"]` أو `img[data-nimg]`
* **سنة الإنتاج والدقة:** `span.yr` و `span.quality`

---

## 4. هندسة المشاهدة وسيرفرات البث (Streaming & FastDL Engine)

1. **الوصول لصفحة السيرفرات:**
   من صفحة الفيلم، يتم استخراج رابط التحميل والبث الموجه إلى `m4udl.store/download/{slug}`.
2. **استخراج روابط البث داخل بوابة m4udl:**
   تحتوي الصفحة على روابط مصنفة بالجودة:
   * **1080p FHD Fast Server:** روابط HLS مباشرة أو روابط Google Drive / HubCloud فائقة السرعة.
   * **720p HD Server:** روابط بديلة بحجم أصغر وسرعة تشغيل فورية.
   * **480p SD Mobile:** روابط خفيفة للأجهزة المحمولة وباقات الإنترنت المحدودة.

---

## 5. خوارزمية الربط بتطبيق زقزوقة IPTV

1. **البحث الموازي:** يقوم التطبيق بإرسال الكلمة المفتاحية لنقطة `/?s={query}`.
2. **استخراج معرف الفيلم (Slug):** تحويل الرابط تلقائياً إلى رابط بوابة `m4udl.store`.
3. **توليد روابط المشغل:**
   * سحب روابط البث وتمرير الجودة الافتراضية 1080p إلى ExoPlayer.
   * في حال كانت الروابط محمية بروابط إعادة توجيه قصيرة، يقوم مشغل WebView الداخلي بفك التحويل تلقائياً في الخلفية خلال ثانية واحدة والبدء في التشغيل.
