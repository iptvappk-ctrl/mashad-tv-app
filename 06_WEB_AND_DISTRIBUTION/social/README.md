---

### 📂 محتويات المجلد بالتفصيل

1. **`docs/SITES_DATABASE_100.md`**:
   - قاعدة بيانات تضم **أكثر من 110 موقع** مصنفة تفصيلياً:
     - 45 موقع سينما ومسلسلات عربية ومصرية (عرب سيد، وي سيما، فاصل، أكوام، إيجي بست، سيما فور يو...)
     - 25 موقع متخصص في الدراما التركية (قصة عشق، ديزيماج، تورك فان، ديزي نت، أوزون...)
     - 25 موقع متخصص في عالم الأنمي وسبيستون (أنمي بلكم، شاهيد أنمي، أنمي سلاير، أنمي فليكس...)
     - 20 موقع متخصص في السينما الأجنبية وهوليوود (شبكتي سينمانا، ريل أكشن، موفيز لاند...)
   - تفاصيل الدومينات، أنواع السيرفرات السحابية لكل موقع، وطرق فك التشفير والسحب.

2. **`docs/SYSTEM_ARCHITECTURE_AND_FLUTTER_GUIDE.md`**:
   - شرح معماري شامل لكيفية عمل النظام وتخطي الإعلانات 100%.
   - كود Dart / Flutter الجاهز للنسخ في مشروعك (`StreamResolverService`).
   - كود مشغل الفيديو Flutter مع ميزة التنقل الفوري بين السيرفرات (Smart Fallback).
   - كود التحميل السريع المباشر في الخلفية واستئناف التنزيل.
   - كود مشغل الويب (HTML5 / Hls.js).

3. **`src/lib/extractors/stream-extractor.ts`**:
   - المحرك البرمجي الأساسي لفك وتجريد روابط المشاهدة من الإعلانات.
   - يدعم أكثر من 15 مضيف سحابي (Govid, Doodstream, Streamtape, Uqload, Mixdrop, Voe.sx, Fembed, Mp4upload, Filelions, Turboviplay, إلخ).
   - دوال `extractStreamFromEmbed` و `extractStreamWithFallback`.

4. **`src/lib/providers/`**:
   - المزودات البرمجية المهيأة للسحب والبحث الفوري:
     - `super-aggregator.ts` (المجمع الشامل مع Smart Race Fallback)
     - `arabseed.ts` (عرب سيد)
     - `wecima.ts` (وي سيما)
     - `faselhd.ts` (فاصل اعلاني)
     - `akwam.ts` (أكوام)
     - `egybest.ts` (إيجي بست)
     - `cima4u.ts` (سيما فور يو)
     - `turkish.ts` (الدراما التركية - مترجم ومدبلج)
     - `anime.ts` (عالم الأنمي)
     - `foreign.ts` (السينما الأجنبية وسينمانا)
     - `types.ts` & `utils.ts`

5. **`src/api/`**:
   - مسارات الـ API الجاهزة للربط:
     - `/api/cinema/superresolve`: استخراج رابط البث النقي مع التنقل التلقائي عند تعطل أي سيرفر.
     - `/api/proxy/stream`: البروكسي المعقم لتنظيف الـ M3U8 وتجاوز الـ CORS ودعم الـ Range Requests للتقديم والتحميل الفوري.
     - `/api/cinema/providers`: قائمة المواقع وحالتها.
