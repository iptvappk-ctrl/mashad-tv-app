# 🚀 منصة الويب، سيرفر التحليلات، ودليل البناء (Web, Dashboard & Deployment Guide)
## التوثيق التقني لمنظومة التشغيل المتكاملة

تشتمل منظومة مشهد TV على ثلاثة مكونات رئيسية تعمل بتكامل تام:
1. **تطبيق الأندرويد المحمي (MadarTV / Mashad Mobile App)**
2. **منصة الويب السينمائية (Mashad Web Platform - Next.js 14)**
3. **خادم التحليلات والرصد اللحظي (Mashad Telemetry & Analytics Server)**

---

## 1. منصة الويب السينمائية (Mashad Web App)

تقع المنصة داخل مجلد `web/`، وهي مبنية بأحدث تقنيات الويب الحديثة:
- **إطار العمل:** Next.js 14 (App Router) مع React 18 و TypeScript.
- **التصميم:** Tailwind CSS مع نظام ألوان داكن فخم وهوية مشهد الذهبية.
- **المشغل:** Video.js و HLS.js لتشغيل روابط `.m3u8` مباشرة في المتصفح مع تغطية العلامات المائية.
- **مسارات الـ API:** (`/api/cinema/category`, `/api/cinema/detail`, `/api/yacine/channels`).

### أوامر التشغيل:
```powershell
cd "c:\Users\hassa\Desktop\all project\iptv app\web"
npm install    # (لأول مرة فقط)
npm run dev
```
تعمل المنصة على الرابط: `http://localhost:3000`

---

## 2. خادم التحليلات والرصد اللحظي (Analytics Server)

يقع الخادم داخل مجلد `dashboard/` (أو `Mashad_Dashboard/`):
- **البيئة:** Node.js مع Express.
- **الوظيفة:** رصد النشاط الحي للتطبيق لحظة بلحظة:
  - عدد المستخدمين النشطين حالياً في التطبيق والويب.
  - الأفلام والمسلسلات الأكثر مشاهدة اليوم.
  - القنوات الأكثر متابعة في البث المباشر.
  - نبضات الجلسات (Heartbeats) لضمان استقرار البث.

### أوامر التشغيل:
```powershell
cd "c:\Users\hassa\Desktop\all project\iptv app\dashboard"
node server.js
```
يعمل الخادم ولوحة التحكم المباشرة على: `http://localhost:4040`

## 3. مركز التحكم والتشغيل الموحد (`start_ecosystem.bat`)

لتسهيل إدارة المنظومة بالكامل بنقرة زر واحدة دون الحاجة لكتابة أوامر سطر الأوامر، تم إنشاء ملف دفعي ذكي في جذر المشروع:
`c:\Users\hassa\Desktop\all project\iptv app\start_ecosystem.bat`

عند تشغيله، تظهر قائمة تفاعلية بالخيارات:
```
================================================================
      📺 منظومة مَـشْـهَـدْ TV — مركز التحكم والتشغيل
================================================================

 [1] تشغيل خادم التحليلات والرصد (Port 4040) وفتح اللوحة
 [2] تشغيل منصة الويب السينمائية (Port 3000)
 [3] بناء تطبيق الأندرويد المشفر (Release APK)
 [4] فتح لوحة التحكم في المتصفح مباشرة
 [5] تشغيل كل الخدمات معاً (السيرفر + منصة الويب + اللوحة)
 [0] خروج

================================================================
```
