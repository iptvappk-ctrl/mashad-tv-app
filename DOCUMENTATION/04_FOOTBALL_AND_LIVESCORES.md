# ⚽ محرك المباريات والنتائج الحية (Football Matches & Live Scores)
## التوثيق التقني لملف `FootballRepository.kt` و `FootballWidget.kt`

يقوم هذا المحرك بمتابعة ورصد جميع مباريات كرة القدم في الدوريات العالمية الكبرى، وجلب النتائج المباشرة لحظة بلحظة، وعرضها في ودجت تفاعلي أنيق داخل التطبيق مع ربطها التلقائي بالقنوات الناقلة.

---

## 1. مصادر البيانات والتكامل مع شبكة ESPN الرياضية

يعتمد المحرك على نقطة وصول رسمية وعالية الدقة من شبكة ESPN العالمية:
- **قالب الرابط:** `https://site.api.espn.com/apis/site/v2/sports/soccer/%s/scoreboard`
- يتم استبدال `%s` برمز الدوري المعني.

### البطولات والدوريات المدعومة حالياً:
| كود البطولة | اسم البطولة |
|:---:|:---|
| `eng.1` | الدوري الإنجليزي الممتاز (Premier League) |
| `esp.1` | الدوري الإسباني (La Liga) |
| `ita.1` | الدوري الإيطالي (Serie A) |
| `ger.1` | الدوري الألماني (Bundesliga) |
| `fra.1` | الدوري الفرنسي (Ligue 1) |
| `uefa.champions` | دوري أبطال أوروبا (UEFA Champions League) |

## 2. السحب المتوازي السريع عبر Kotlin Coroutines

لضمان عدم تأخر الواجهة أثناء جلب مباريات 6 دوريات في نفس الوقت، يعتمد الكود على تنفيذ متزامن غير متزامن (Parallel Execution):

```kotlin
coroutineScope {
    val deferreds = LEAGUES.map { (code, name) ->
        async(Dispatchers.IO) {
            fetchLeagueMatches(code, name)
        }
    }
    // انتظار انتهاء جميع الطلبات ودمج القوائم
    val all = deferreds.awaitAll().flatten()
}
```
بهذه التقنية، يتم جلب مباريات كافة الدوريات في أقل من 700 ميلي ثانية.

## 3. خوارزمية ترتيب وأولوية المباريات (Smart Match Sorting)

المستخدم يهتم أولاً بالمباريات التي تُلعب الآن. لذلك تم بناء ترتيب مخصص يعتمد على حالة المباراة:
1. **المباريات الجارية حالياً (`state == "in"`):** تأتي في قمة القائمة ويظهر بجانبها عداد الدقائق وتوهج أحمر حي (LIVE 🔴).
2. **المباريات القادمة اليوم (`state == "pre"`):** تأتي في المرتبة الثانية مع عرض توقيت الانطلاق بدقة حسب التوقيت المحلي للمستخدم.
3. **المباريات المنتهية (`state == "post"`):** تأتي في نهاية القائمة مع عرض النتيجة النهائية للمباراة.

```kotlin
val sorted = all.sortedWith(
    compareBy<FootballMatch> {
        when (it.state) {
            "in" -> 0    // الأولوية القصوى: جارية الآن
            "pre" -> 1   // ستبدأ قريباً
            else -> 2    // انتهت
        }
    }.thenBy { it.matchDate }
)
```

## 4. البيانات المستخرجة لكل مباراة (`FootballMatch`)

- **الفريقان:** الاسم باللغة العربية وشعار كل فريق بدقة عالية (PNG/SVG).
- **النتيجة الحية:** أهداف الفريق المضيف والضيف مع تحديث فوري عند تسجيل أي هدف.
- **توقيت المباراة:** الدقيقة الحالية من الشوط الأول أو الثاني، أو الوقت الإضافي.
- **اسم البطولة:** شعار الدوري وتصنيفه.
- **القناة الناقلة المقترحة:** الربط الذكي مع قنوات beIN Sports أو SSC في قسم البث المباشر.

## 5. نظام الكاش وتوفير استهلاك البيانات (Smart Caching)
- تم تزويد المحرك بكاش مؤقت في الذاكرة الحية (`CACHE_TTL = 3 دقائق`).
- إذا أعاد المستخدم فتح الواجهة خلال 3 دقائق، يتم عرض المباريات فوراً بدون أي استدعاء جديد للشبكة، مما يوفر استهلاك بطارية الهاتف وحزم البيانات ويضمن تجربة تصفح فورية (Instant Loading).
