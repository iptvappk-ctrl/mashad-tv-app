## 1. شجرة التنقل والمكدس العميق (Navigation Back-Stack)

في تطبيقات السينما، يدخل المستخدم في مسارات تصفح متداخلة:
`الرئيسية ➔ مسلسل قيامة عثمان ➔ الحلقة 5 ➔ الحلقة 6 ➔ الموسم الثاني ➔ الحلقة 1`

### المشكلة السابقة:
كان التطبيق يعتمد على متغير واحد (`openedItem`) لتحديد العنصر المفتوح. وعندما يضغط المستخدم زر "رجوع" (Back)، كان التطبيق يغلق صفحة التفاصيل ويعود فوراً إلى الشاشة الرئيسية، مما يُفقد المستخدم مسار تصفحه.

### الحل المبتكر: نظام المكدس (`itemStack: List<String>`)
تم تحويل نظام التنقل إلى قائمة مكدس ديناميكية:
```kotlin
// حفظ مسار التصفح في الـ State
var itemStack by rememberSaveable { mutableStateOf(emptyList<String>()) }

// العنصر المعروض حالياً هو آخر عنصر في المكدس
val currentItem = remember(itemStack, allItems) {
    allItems.firstOrNull { it.pageUrl == itemStack.lastOrNull() }
}

// عند فتح حلقة أو جزء جديد: يتم دفعه (Push) في المكدس
onOpenItem = { newItem ->
    allItems = (allItems + newItem).distinctBy { it.pageUrl }
    itemStack = itemStack + newItem.pageUrl
}

// عند الضغط على زر الرجوع: يتم سحب آخر عنصر فقط (Pop)
onBack = {
    itemStack = itemStack.dropLast(1)
}
```
**النتيجة:** أصبح زر الرجوع يعيد المستخدم إلى الحلقة السابقة أو المسلسل الأب بمنتهى السلاسة والاحترافية.

تمت هندسة صفحة التفاصيل في قائمة رأسية واحدة (`LazyColumn`) بمرونة فائقة:

- **تمييز الحلقة الحالية:** تظهر الحلقة المفتوحة حالياً بخلفية ذهبية داكنة وإطار ذهبي مضيء وبادج `الحلقة الحالية 🔴`.
- **أزرار القفز السريع (Next / Prev):** زر "الحلقة التالية" باللون الذهبي البارز وزر "الحلقة السابقة" باللون الداكن مع رقم الحلقة لتسهيل المتابعة المتتالية.

## 3. المشغل الهجين فائق السرعة (`MashadPlayerScreen`)

يجمع المشغل بين أفضل خيارين لتشغيل الفيديو:

### المسار الأول (المفضل): Native ExoPlayer
- إذا تمكن المحرك من فك تشفير رابط الـ `.m3u8` أو `.mp4`، يتم تمريره فوراً إلى مكتبة `Media3 / ExoPlayer`.
- **المميزات:** استهلاك بطارية شبه معدوم، تشغيل عتادي مباشر (Hardware Acceleration)، واستجابة فورية بدون إعلانات.

### المسار الثاني (البديل): Sandboxed WebView Fallback
- في حال كان السيرفر يعتمد على حماية معقدة أو مشغل خاص به، يقوم التطبيق بتشغيل `WebView` مجهز خصيصاً:
  - **حظر النوافذ المنبثقة:** منع `window.open` و `setSupportMultipleWindows(false)` لمنع فتح صفحات الإعلانات.
  - **حقن CSS/JS تلقائي:** إخفاء قوائم الموقع الأصلية وفرض تمدد المشغل ليملأ الشاشة بنسبة 100% (Edge-to-Edge).
  - **التدوير التلقائي:** يتم تحويل الهاتف تلقائياً إلى الوضع الأفقي (Landscape) وإخفاء شريط الإشعارات وأزرار النظام السفلية، وإعادتها فور إغلاق المشغل.
