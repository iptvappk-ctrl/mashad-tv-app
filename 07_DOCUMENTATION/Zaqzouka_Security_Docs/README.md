# 🛡️ زقزوقة TV - التوثيق الرسمي لمنظومة الأمان والتحكم الشامل

هذا المجلد يحتوي على كافة الوثائق الهندسية المشفرة وتعليمات إدارة منظومة التحكم الأعلى في تطبيق زقزوقة TV ومشغل ZAG Player، لضمان السيطرة الكاملة والحماية من أي غدر أو تعديل غير مصرح به.

---

## 📑 فهرس الوثائق:

1. [دليل تطبيق التحكم الأعلى (Master Control App)](MASTER_CONTROL_SYSTEM.md):
   - شرح تطبيق `ZaqzoukaMasterControl`.
   - آلية عمل الأزرار الثلاثة: التجميد، التدمير والمسح الشامل (عليا وعلى أعدائي)، والاستعادة.
   - تشفير القبو المحلي (Encrypted Vault) بنظام AES/SHA-256 لحفظ السيرفرات في أمان.

2. [قواعد حماية فايربيس (Firebase Security Rules)](FIREBASE_SECURITY_RULES.md):
   - كيف نمنع أي شخص فك الـ APK من الوصول أو تعديل أو مسح السيرفرات.
   - قواعد الأمان الصارمة لقاعدة البيانات Realtime Database و Cloud Firestore.

3. [دليل مركز التحديثات الفورية على Vercel (Vercel OTA Hub)](VERCEL_OTA_HUB_GUIDE.md):
   - خطوات رفع واستضافة موقع التحديثات الفوري على Vercel.
   - كيفية دفع تحديث جديد ليصل لكل الهواتف تلقائياً بدون متجر.
