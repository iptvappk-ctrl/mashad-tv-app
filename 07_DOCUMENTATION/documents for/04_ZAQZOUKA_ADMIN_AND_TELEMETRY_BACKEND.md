## 1. نظرة عامة على المنظومة والربط المركزي
تشكل لوحة تحليلات زقزوقة (`ZaqzoukaAdmin`) والسيرفر السحابي المصغر (`dashboard-api`) العقل المدبر والمركز العصبي لكامل منظومة البث (التطبيق والموقع والمشغل):
- **رصد حي 100% بدون بيانات وهمية:** يتم عرض الجلسات الحقيقية المتصلة بالسيرفر لحظة بلحظة مع مؤشر استجابة السحابة (Ping Latency ms).
- **مركز قيادة متكامل من 8 تبويبات:** يوفر للمشرف رؤية كاملة لسلامة السيرفرات، وأداء المشغل، وحركة الموقع والتطبيق، والأهم من ذلك: تحويل بيانات المشاهدة إلى أرباح مالية حقيقية.

## 2. هندسة تطبيق لوحة التحكم والأقسام الثمانية (ZaqzoukaAdmin - 8 Tabs)
تم بناء التطبيق بإطار عمل Flutter مع دعم كامل لثيمين (Light / Dark) وتبديل سلس ومؤشرات ملونة:

```
┌────────────────────────────────────────────────────────────────────────┐
│                      لوحة تحليلات زقزوقة TV                            │
│           🟢 متصل بالسحابة · 419 ms · Vercel Serverless                │
├────────────────────────────────────────────────────────────────────────┤
│ [1. نظرة عامة] [2. الجلسات الحية] [3. داشبورد الموقع] [4. سوق الداتا 💎] │
│ [5. الرادار]   [6. الأداء والجودة] [7. صحة السيرفرات] [8. الأمان والبصمة] │
└────────────────────────────────────────────────────────────────────────┘
```

### تفصيل التبويبات الثمانية:
1. **نظرة عامة (Overview KPIs):**
   - إجمالي الجلسات المسجلة عبر المنظومة.
   - الجلسات النشطة الآن 🟢 (تحديث لحظي كل 10 ثوانٍ).
   - إجمالي دقائق المشاهدة وسرعة استجابة السيرفر.
   - نسبة حركة المستخدمين بين التطبيق والموقع (App vs Web Traffic Ratio).
2. **الجلسات الحية (Live Sessions & Location Details):**
   - بطاقات الجلسات المفتوحة الآن مع علم الدولة، والموقع الدقيق: `📍 القاهرة، C، مصر (EG)`.
   - شارة تصنيف الجمهور الإعلاني: `🎯 🍿 جمهور الترفيه والمنوعات`.
   - نوع الجهاز ومزود خدمة الإنترنت (ISP).
   - نافذة تفاصيل منبثقة (Details Modal Bottom Sheet) عند النقر على أي جلسة تعرض كافة التفاصيل الفنية ومدة الجلسة بالثواني والشريحة الإعلانية وسعر الـ eCPM المتوقع.
3. **داشبورد الموقع (Web Portal Analytics):**
   - إحصائيات زوار الموقع الإلكتروني حصراً.
   - نسبة زوار الويب من إجمالي حركة المرور.
   - تحليل متصفحات الزوار (Chrome, Safari, Edge, Firefox, Samsung Internet).
   - سجل الجلسات الحية القادمة من متصفحات الويب.
4. **سوق الداتا والإعلانات 💎 (Audience & Ad Monetization Hub):**
   - **بطاقة القيمة السوقية المقدرة:** حساب العائد المالي المتوقع شهرياً ويومياً بالدولار والجنيه المصري.
   - **4 بطاقات مالية رئيسية:**
     - إجمالي المشاهدات المؤهلة لإعلانات الفيديو (Monetized Video Plays).
     - الأرباح اليومية المقدرة من إعلانات الفيديو VAST/VMAP.
     - الأرباح الشهرية المتوقعة ($ و EGP).
     - عدد ملفات الجمهور المصنفة للبيع لسماسرة الـ DMP.
   - **أزرار التصدير بنقرة واحدة:**
     - تحميل ملف الجمهور بصيغة CSV (`/api/export/audience?format=csv`).
     - تحميل ملف الجمهور بصيغة JSON (`/api/export/audience?format=json`).
     - تحميل تقرير اتجاهات السوق الاستخباري المعتمد Trend Report.
   - **الاستهداف الجغرافي للمدن الأكثر طلباً للمعلنين:** توزيع المشاهدين في القاهرة، الجيزة، الإسكندرية، الرياض، دبي، إلخ.
   - **توزيع شرائح الجمهور (Audience Segments Breakdown):** نسب جمهور الرياضة، الترفيه، الأنمي، العائلة.
   - **دليل كبار المشترين المعتمدين (Verified Buyers Playbook):** تفاصيل التعاقد مع Google AdManager, AppLovin, LiveRamp, Lotame والأسعار الفعلية.
5. **الرادار والملخص (Live Radar & Distribution):**
   - توزيع أنواع الأجهزة (شاشات Smart TV، هواتف أندرويد، متصفحات كمبيوتر).
   - توزيع أنظمة التشغيل (Android 14, 15, Windows, iOS, Mac).
   - أكثر الأفلام والمسلسلات مشاهدة وساعات الذروة.
6. **الأداء والجودة (Quality of Service & Latency):**
   - زمن تحميل الفيديو الأولي (Time-to-First-Frame).
   - أحداث التخزين المؤقت وتوقف البث (Buffer Stall Events).
   - سجل أخطاء تشغيل السيرفرات (Error Logs).
7. **صحة السيرفرات والتنبيهات (Server Health & Alerts):**
   - فحص استجابة سيرفرات البث الرئيسية (Voe, Vidmoly, Vidara).
   - رصد عمليات التبديل التلقائي (Failover Events Monitor).
   - سجل التنبيهات الفنية اللحظية.
8. **الأمان والبصمة الرقمية (Security & Device Fingerprints):**
   - فحص عناوين IP المشبوهة أو محاولات إغراق السيرفرات بطلبات زائدة (Rate Limiting).
   - البصمة الرقمية للأجهزة (Hardware Architecture & Screen Resolution).

## 3. هندسة السيرفر السحابي وقواعد البيانات (Serverless API & Firebase RTDB)
الملف: `dashboard-api/` المنشور على سحابة Vercel

### مسارات الـ Serverless المعتمدة:
| المسار (Endpoint) | الوظيفة |
|---|---|
| `POST /api/telemetry/session/start` | بدء جلسة جديدة وحفظ تفاصيل الجهاز والموقع الجغرافي الدقيق |
| `POST /api/telemetry/session/ping` | استقبال نبضة البقاء حياً (Heartbeat) وتحديث مدة المشاهدة |
| `POST /api/telemetry/session/end` | إنهاء الجلسة وإغلاقها |
| `GET /api/stats` | تجميع الإحصائيات الشاملة، والمدن، والشرائح الإعلانية، والعوائد المالية |
| `GET /api/export/audience` | تصدير شرائح الجمهور المصنفة المتوافقة مع IAB بصيغة CSV أو JSON |
| `GET /api/export/trends` | توليد تقرير اتجاهات السوق الاستخباري لصناع المحتوى والمعلنين |

## 4. محرك التحديد الجغرافي فائق الدقة (Exact Geolocation & ISP Engine)
الملف: `dashboard-api/api/_lib.js`

### آلية العمل الهندسي:
1. **استخراج عنوان الـ IP الحقيقي:** فحص ترويسات البروكسي (`x-forwarded-for`, `x-real-ip`).
2. **الاستعلام والمطابقة الفورية:** يتم مطابقة الـ IP مع قواعد البيانات الجغرافية واستخراج:
   - اسم المدينة (City) ومفتاح المنطقة/المحافظة (Region).
   - اسم مزود خدمة الإنترنت (ISP).
3. **قاموس التعريب الدقيق (`CITY_MAP_AR` & `REGION_MAP_AR`):**
   - يحتوي على أكثر من 30 مدينة ومحافظة عربية ومصرية:
     - `Cairo` / `Al Qahirah` -> `القاهرة`
     - `Giza` / `Al Jizah` -> `الجيزة`
     - `Alexandria` / `Al Iskandariyah` -> `الإسكندرية`
     - `Tanta` / `Gharbia` -> `طنطا، الغربية`
     - `Mansoura` / `Dakahlia` -> `المنصورة، الدقهلية`
     - `Zagazig` / `Sharqia` -> `الزقازيق، الشرقية`
     - `Port Said` -> `بورسعيد`
     - `Suez` -> `السويس`
     - `Assiut` -> `أسيوط`
     - `Aswan` -> `أسوان`
4. **توليد الموقع النهائي المنسق:**
   - يظهر السجل بالشكل الاحترافي المعتمد: `القاهرة، C، مصر (EG)`.

## 5. محرك تصنيف وتسييل البيانات والإعلانات (Big Data & Ad Monetization Engine)
### الحقيقة الاحترافية: كيف تجني التطبيقات الكبرى الملايين من الداتا والإعلانات؟
لا تقوم أي شركة كبرى ببيع ملفات تحوي أرقام هواتف أو أسماء، وإنما يتم تسييل **سلوك المشاهدة المجهول (Anonymous Audience Segments)** عبر 4 قنوات رئيسية:

### 1. إعلانات الفيديو الرقمية داخل المشغل (Video Pre-Roll Ads via VAST/VMAP):
- تمثل **90% من إجمالي دخل التطبيقات**.
- **المشترون:** Google AdManager, AppLovin MAX, Unity Ads, Prebid.
- **الأسعار السوقية المعتمدة (eCPM - سعر الألف ظهور فيديو):**
  - مصر والوطن العربي: **\$3.00 إلى \$8.00** لكل 1,000 مشاهدة إعلان.
  - دول الخليج (السعودية والإمارات): **\$12.00 إلى \$25.00** لكل 1,000 مشاهدة إعلان.
- **الحسبة بالأرقام:**
  - 20,000 مشاهد يومياً = 20 × \$5 = \$100 يومياً = **\$3,000 شهرياً (قرابة 150,000 جنيه مصري شهرياً)** من إعلانات الفيديو وحدها!

### 2. منصات إدارة البيانات وسماسرة الجمهور (DMPs - Data Management Platforms):
- **المشترون:** LiveRamp, Lotame, Eyeota.
- **ماذا يشترون؟** ربط معرفات الجمهور المجهولة (Mobile Advertising IDs / Web Cookies) المصنفة بحسب الاهتمامات.
- **السعر:** **\$0.50 إلى \$2.00** لكل 1,000 ملف تعريفي شهرياً.

### 3. تقارير اتجاهات المشاهدة واستخبارات السوق (Trend Intelligence Reports):
- **المشترون:** شركات الإنتاج الفني، وكالات الدعاية والإعلام، وموزعو المحتوى.
- **ماذا يشترون؟** تقارير مجمعة مثل: *"أكثر 50 مسلسلاً بحثاً ومشاهدة في مصر مع ساعات الذروة وتوزيع المحافظات لعام 2026"*.
- **السعر:** يباع التقرير الواحد بمبالغ تتراوح بين **\$500 إلى \$2,000** للتقرير الواحد المنسق.

### 4. الرعاة المباشرون (Direct Brand Sponsorships):
- رعاية أقسام مخصصة لعلامات تجارية ذات صلة (مثل رعاية قسم المباريات الحية لمعلن رياضي، أو رعاية قسم الأنمي لمتجر ألعاب).
- **السعر:** تعاقد شهري ثابت يتراوح بين **\$500 إلى \$3,000 شهرياً** لكل قسم.

## 6. واجهات تصدير البيانات وسوق المشترين (Data Export APIs & Buyer Playbook)
1. **تصدير ملف الجمهور المتوافق مع IAB (`/api/export/audience`):**
   - يدعم التصدير بصيغتي **CSV** و **JSON**.
   - يحتوي الحقول التالية المتوافقة مع معايير LiveRamp و Lotame:
     - `Anonymous_Profile_ID`
     - `IAB_Audience_Segment`
     - `Target_Location_City`
     - `Country_Code`
     - `Device_Platform`
     - `ISP_Provider`
     - `Estimated_eCPM_Tier`
2. **تصدير تقرير اتجاهات السوق (`/api/export/trends`):**
   - وثيقة استخبارية متكاملة بقيمة سوقية \$1,000 تحتوي على أكثر المحتويات طلباً، ساعات الذروة، ونسب تفاعل المحافظات.

## 7. الأمان، الخصوصية، والامتثال القانوني (Security & Privacy Compliance)
- **توافق كامل مع قانون حماية البيانات الشخصية المصري رقم 151 لسنة 2020:**
  - لا يتم تخزين أي أسماء، أو أرقام هواتف، أو حسابات بنكية، أو بيانات شخصية (Zero PII Collection).
- **توافق كامل مع المعايير الأوروبية GDPR ومعايير كاليفورنيا CCPA:**
  - كافة المعرفات عبارة عن تشفير أحادي الاتجاه (Cryptographic SHA-256 Hash).
  - يتم حذف سجلات الـ IP الدقيقة واستبدالها بالمدينة والمحافظة فقط لحماية خصوصية المستخدمين.
