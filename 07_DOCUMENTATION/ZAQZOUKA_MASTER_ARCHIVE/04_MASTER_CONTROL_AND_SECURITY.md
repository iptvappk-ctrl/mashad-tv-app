# 💥 دليل نظام التحكم المركزي والحماية الشاملة (Master Control & Security)

> **شعار المنظومة:** *"أنا المتحكم رقم 1 في المنظومة والمنصة كلها.. وإذا حدث أي غدر، في ثوانٍ تنهار المنظومة بالكامل: عليا وعلى أعدائي!"*

---

## 🎯 نظرة عامة على نظام التحكم الأمني

نظام التحكم المركزي **Zaqzouka Master Control** هو تطبيق فلاتر مستقل تماماً وخاص بهاتف المالك الشخصي فقط. تم بناؤه بأعلى معايير التشفير والأمان ليعطيك السيطرة المطلقة على كل هاتف مثبت عليه تطبيق "زقزوقة تيفي" أو مشغل "ZAG Player" في العالم.

---

## 📱 الأزرار الثلاثة للتحكم المركزي

### 1. ❄️ زر الإيقاف والتعطيل الفوري (Emergency Kill-Switch):
- **الهدف:** إيقاف المنظومة مؤقتاً عند الحاجة للصيانة أو عند حدوث خلاف مع أي شريك/مستخدم.
- **ماذا يحدث عند الضغط عليه؟**
  1. يرسل أمراً فورياً مشفراً إلى سيرفر التحكم ويغير قيمة `system_status` إلى `"frozen"`.
  2. في نفس الثانية، تستقبل جميع الهواتف العاملة الإشارة اللحظية عبر Firebase Realtime Database.
  3. يغلق المشغل أي بث فوري ويمنع فتح أي قناة أو فيلم.
  4. تظهر شاشة تحذيرية باللون الأسود في جميع الأجهزة: *"الخدمة متوقفة مؤقتاً لأعمال الصيانة والتطوير"*.
  5. لا يمكن لأي مستخدم تجاوز هذه الشاشة أو تشغيل أي محتوى.

---

### 2. 💥 زر المسح والتدمير الشامل (Nuclear Remote Wipe - عليا وعلى أعدائي):
- **الهدف:** إذا غدر بك أحد أو حاول سرقة المشروع أو حرمانك من حقوقك، يقوم هذا الزر بمسح كل أثر للمنظومة على مستوى العالم.
- **ماذا يحدث عند الضغط عليه؟**
  1. يتطلب تأكيداً ثنائياً بكتابة الرمز السري لمنع الضغط الخطأ.
  2. تتغير قيمة `system_status` إلى `"wiped"`.
  3. يقوم السيرفر السحابي فوراً بتصفير وحذف جميع السيرفرات، الروابط، والقنوات المخزنة على السحابة، لتصبح الحقول فارغة تماماً.
  4. تبث السحابة أمراً فورياً لكل الهواتف باستدعاء دالة الأندرويد الأصلية `cache.clearAll` عبر الـ MethodChannel:
     - مسح جميع سجلات `SharedPreferences`.
     - حذف ملفات الكاش المحلي وقواعد بيانات `SQLite`.
     - تصفير السيرفرات المخزنة في ذاكرة الهاتف.
  5. يصبح التطبيق في كل الهواتف خالياً تماماً وكأنه لم يكن به أي محتوى في تاريخه، ولا يستطيع أي شخص حتى لو كان خبيراً استرجاع رابط واحد من الهاتف.

---

### 3. 🔄 زر الاستعادة الشاملة اللحظية (Full Instant Restore):
- **الهدف:** بعد تدمير أو إيقاف المنظومة، عندما تسترد حقك أو ترغب في تشغيلها مجدداً، تستعيد كل شيء بضغطة واحدة في 3 ثوانٍ.
- **كيف تعمل الاستعادة السحرية؟**
  1. يعتمد التطبيق على **الخزنة المحلية المشفرة (Encrypted Offline Vault)** المخزنة في ذاكرة هاتف المالك فقط.
  2. هذه الخزنة مشفرة بخوارزمية `AES-256-GCM` وتحتوي على النسخة الأصلية الكاملة من جميع السيرفرات والقنوات ومفاتيح البث.
  3. عند الضغط على استعادة، يقرأ التطبيق الخزنة المحلية ويفك تشفيرها، ثم يرفع البيانات الأصلية إلى فايربيس دفعة واحدة.
  4. تتغير قيمة `system_status` إلى `"active"`.
  5. تعود جميع الهواتف للعمل فوراً وبشكل طبيعي وكأن شيئاً لم يكن!

## 🛡️ قواعد أمان فايربيس (Firebase Security Rules)

لحماية السحابة من التلاعب، تم اعتماد القواعد الأمنية التالية في `dashboard-api/database.rules.json`:

```json
{
  "rules": {
    "system_control": {
      ".read": true,
      ".write": "auth != null && auth.token.admin === true"
    },
    "servers": {
      ".read": true,
      ".write": "auth != null && auth.token.admin === true"
    },
    "channels": {
      ".read": true,
      ".write": "auth != null && auth.token.admin === true"
    }
  }
}
```

- **القراءة (`.read: true`):** مسموحة لتطبيقات العملاء لكي تستقبل التحديثات اللحظية وحالة المنظومة فوراً.
- **الكتابة (`.write`):** محصورة ومحمية 100% بحساب المشرف المصرح له فقط، بحيث لا يمكن لأي مستخدم عادي أو متطفل تعديل أو حذف أي حرف.

## 📲 تشغيل تطبيق التحكم Master Control

1. ثبت ملف `zaqzouka-master-control.apk` الموجود في مجلد `RELEASE_BINARIES/` على هاتفك الشخصي فقط.
2. عند فتح التطبيق، ستظهر لوحة مفاتيح الأرقام.
3. اكتب الرمز السري: **`999888`**.
4. ستظهر لك شاشة التحكم بالأزرار الثلاثة المضيئة (أخضر للاستعادة والتشغيل، برتقالي للتجميد، وأحمر للتدمير الشامل) مع عرض مباشر للحالة الحالية للمنظومة في الوقت الفعلي.
