## 📌 1. نظرة عامة على الموقع
موقع الويب الرسمي والمخصص لتوزيع وتحميل تطبيقي المنظومة السينمائية مباشرة بروابط فورية سريعة وبدون أي إعلانات أو تعقيدات:
1. **تطبيق زقزوقة TV** (`zaqzouka-app.apk` — حجم 53.4 ميجابايت).
2. **مشغل زاغ ZAG Player** (`zag-player.apk` — حجم 4.6 ميجابايت).

الموقع مصمم بهوية بصرية مخصصة وفخمة تعكس طابع السينما والهدوء (Artisanal Cinema Theme)، بدون أي إيموجيز أو عناصر عشوائية، ويدعم التبديل الفوري بين اللغتين العربية والإنجليزية.

## ⚡ 5. مميزات الموقع التقنية

1. **تحميل مباشر فوري (Direct APK Hosting)**:
   - رابط تحميل زقزوقة TV: `https://zaqzouka-tv.vercel.app/downloads/zaqzouka-app.apk`
   - رابط تحميل مشغل زاغ: `https://zaqzouka-tv.vercel.app/downloads/zag-player.apk`
2. **مولد كود QR فوري مدمج**:
   - إمكانية الضغط على زر مسح الباركود ليظهر للمستخدم QR Code لمسحه بكاميرا الهاتف أو التلفزيون للتحميل الفوري بدون كتابة روابط.
3. **تبديل اللغات الفوري (Instant i18n)**:
   - زر التبديل (AR / EN) يغير النصوص واتجاه الصفحة بالكامل (RTL / LTR) لحظياً بدون إعادة تحميل الصفحة.
4. **شريط سفلي ذكي للهواتف (Sticky Mobile Action Bar)**:
   - عند فتح الموقع من الموبايل، يظهر شريط سفلي ثابت يتيح للمستخدم تحميل التطبيقين بضغطة زر دون الحاجة للبحث عن الأزرار داخل الصفحة.
5. **قسم الأسئلة الشائعة التفاعلي (FAQ Accordion)**:
   - إجابات واضحة حول طريقة التثبيت، سبب وجود تطبيقين، التحديثات، والتوافق مع شاشات التلفزيون.

## 🚀 6. طريقة الرفع والتحديث (Deployment & Updating)

### كيف تنشر أي تعديل جديد في ثوانٍ؟
1. افتح التيرمينال داخل المجلد:
   ```powershell
   cd "c:\Users\hassa\Desktop\all project\iptv app\ZAQZOUKA_OFFICIAL_WEBSITE"
   ```
2. نفذ أمر النشر المباشر لـ Vercel:
   ```powershell
   npx vercel --prod --yes
   ```
3. سيتم الرفع وربط النسخة فوراً على: `https://zaqzouka-tv.vercel.app`.

### كيف تحدث ملفات الـ APK في المستقبل؟
1. ضع ملف الـ APK الجديد لتطبيق زقزوقة داخل مجلد `downloads/` باسم `zaqzouka-app.apk`.
2. ضع ملف الـ APK الجديد لمشغل زاغ داخل مجلد `downloads/` باسم `zag-player.apk`.
3. قم بتعديل رقم الإصدار وحجم الملف في `index.html` (إذا أردت).
4. نفذ `npx vercel --prod --yes` وسيصبح التحديث متاحاً فوراً للمستخدمين حول العالم.

## 🌐 7. ربط دومين خاص مخصص (Custom Domain Setup)
إذا اشتريت دومين خاص (مثلاً: `zaqzouka.com` أو `zaq-tv.com`)، خطوات ربطه بـ Vercel كالتالي:
1. ادخل على لوحة تحكم مشروعك في Vercel:  
   `https://vercel.com/hassans-projects-ff23176e/zaqzouka-tv/settings/domains`
2. اكتب اسم الدومين واضغط **Add**.
3. في لوحة تحكم الدومين (Namecheap / Cloudflare / GoDaddy)، أضف الـ DNS التالي:
   - **Type A**: `@` بالقيمة `76.76.21.21`
   - **Type CNAME**: `www` بالقيمة `cname.vercel-dns.com`
4. خلال دقائق سيتم إصدار شهادة SSL مجانية ويعمل الموقع على دومينك الرسمي مباشرة.
