اربط لوحة الإدارة بخاصية Analytics

لن تظهر بيانات قبل إعداد الوصول. اللوحة لا تستخدم أرقامًا تجريبية.

  1. سجّل تطبيق الويب داخل مشروع Firebase، وأضف إعداداته العامة إلى web/.env.local.
  2. فعّل Google Analytics Data API في مشروع Google Cloud، وأضف حساب خدمة بصلاحية Viewer على خاصية Analytics.
  3. اضبط GA_PROPERTY_ID وبيانات Application Default Credentials في بيئة تشغيل لوحة الإدارة.
  4. لبطاقة أكثر الأعمال مشاهدة، سجّل البُعد المخصص content_title بنطاق الحدث في Analytics.

البحث يُحتسب كعدد فقط؛ نصوص البحث وروابط البث ومعرّفات الأجهزة لا تُرسل إلى اللوحة.
